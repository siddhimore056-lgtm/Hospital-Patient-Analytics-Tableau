## 📌 Project Overview
This project focuses on analyzing hospital patient data to uncover insights regarding patient demographics, consultation revenues, medication costs, and operational efficiencies across different doctor types. 

## 📊 Key Insights & Features
* **Revenue Analysis:** Tracked daily and monthly trends for both Medication Revenue and Consultation Revenue.
* **Cost Metrics:** Evaluated financial impacts by comparing Lab Costs against overall patient consultations.
* **Operational Performance:** Segmented data by Doctor Type to identify high-performing departments.

## 🛠️ Tools Used
* **Tableau Desktop / Public** (Data Visualization & Dashboarding)
* **Microsoft Excel** (Kaggle)
